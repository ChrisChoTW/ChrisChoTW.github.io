技術背景

從後端開發起步，逐步成長為技術架構師與團隊領導者。不僅具備深厚的技術實力，更擅長透過技術決策帶動團隊成長，建立可持續的工程文化。

相信真正的技術領導不只是解決技術問題，而是透過系統性思維與設計模式建立可維護、可擴展的技術體系。在每一次重構與架構設計中，都旨在為團隊建立可複製的最佳實踐。

專業理念

信奉技術決策驅動團隊成長的理念。在每一次系統設計中，不僅考慮技術可行性，更重視如何透過這個過程提升團隊能力。希望每一次技術挑戰都能成為團隊的學習機會。

擅長將複雜的技術決策轉化為團隊可理解的方向。透過 Code Review、技術分享會等方式，讓每位成員都能在實際專案中學習成長。知識分享而非藏私，是我建立團隊文化的核心原則。

相信優秀的技術團隊不只是能力的累加，更是文化與標準的建立。透過建立技術文檔、統一開發標準、推動測試文化，讓團隊的每一份努力都能成為組織的資產。
