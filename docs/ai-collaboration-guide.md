## CSS 翻轉卡片位置問題

**日期**: 2025-01-21
**專案**: AI 時代學習典範轉移頁面
**問題類型**: CSS 定位與權重衝突

### 問題現象
卡片翻轉後，背面內容「掉到下面」，沒有完全取代正面位置。

### 根本原因
- Tailwind CSS 的 `flex flex-col` 類別設定了 `position: relative`
- 自定義 CSS `.card-face { position: absolute; }` 被覆蓋
- 兩個卡片面垂直排列而非重疊

### 無效的問題描述
❌ "翻轉效果不對"
❌ "卡片有問題"
❌ "動畫壞掉了"
❌ "看不到內容"

### 有效的問題描述
✅ "翻轉卡片後，內容掉到下面/位置偏移"
✅ "卡片翻轉後背面內容沒有在正確位置"
✅ "兩個卡片面沒有重疊，而是垂直排列"
✅ "請檢查 CSS 權重問題"
✅ "請確認兩個 card-face 是否真的重疊"

### 最佳表達方式
**視覺現象** + **技術檢查要求**：
> "卡片翻轉後背面內容位置偏移，沒有完全取代正面位置。請用瀏覽器開發者工具檢查兩個 .card-face 元素的實際 position 屬性，看是否都是 absolute，以及是否被 Tailwind CSS 覆蓋。"

### 解決方案
使用 `!important` 覆蓋 CSS 框架：
```css
.card-face {
    position: absolute !important;
    top: 0 !important;
    left: 0 !important;
    backface-visibility: hidden !important;
}
```

### 學習要點
1. **具體描述視覺問題**：說出看到的現象
2. **指明檢查方向**：告訴 AI 用什麼工具檢查什麼
3. **考慮 CSS 框架衝突**：現代開發常遇到權重問題
4. **要求實際驗證**：讓 AI 用開發者工具確認

## 表達技巧總結

### ✅ 有效表達原則
1. **具體且可量化**：用數字、像素、時間等具體單位
2. **視覺化描述**：說出看到的現象
3. **提供上下文**：說明在什麼情況下發生
4. **指明檢查工具**：告訴 AI 用什麼方式驗證
5. **分步驟請求**：複雜問題拆成小步驟

### ❌ 無效表達模式
1. **過於籠統**：「不行」、「壞掉」、「有問題」
2. **缺乏上下文**：沒說明觸發條件
3. **混合多個問題**：一次描述太多不相關問題
4. **只說結果不說過程**：沒描述操作步驟

### 🎯 最佳實踐
**問題公式**: `[操作步驟] → [實際結果] ≠ [預期結果] + [請檢查XX]`

**範例**:
> 點擊語言學習卡片 → 背面內容出現在下方 ≠ 背面內容應該完全取代正面 + 請檢查兩個 div 是否重疊及 CSS 權重
