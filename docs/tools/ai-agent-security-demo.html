🛡️ AI 安全防禦指南

⚡ 立即行動清單

1 檢查擴充功能

立即檢視瀏覽器擴充功能，停用或移除不明的 AI Agent

2 修改密碼

更改重要帳號密碼，特別是工作信箱和金融帳戶

3 啟用 2FA

為所有重要帳號啟用雙因素認證，提高安全性

🎯 長期安全策略

環境隔離

建立專門的測試環境，不要在主要工作環境中使用實驗性的 AI 工具。

權限控制

嚴格控制 AI Agent 的權限範圍，只給予完成任務所需的最小權限。

保持警覺

對任何要求總結或處理敏感內容的請求保持懷疑態度。

定期審查

定期檢查並審查授權給各種應用程式的權限和存取範圍。
