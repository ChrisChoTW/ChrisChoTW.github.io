# KPI 指標分析工具 - 產品需求文件

## 📋 基本資訊
- **產品名稱**: KPI 指標分析工具
- **技術架構**: 原生 JavaScript + Gemini AI + CSS3 動畫
- **更新日期**: 2025-09-21

## 🎯 產品定位
團隊 KPI 指標風險識別與理性對談工具

## 核心功能
- KPI 指標風險分析
- 工程師行為洞察
- AI 驅動內容生成
- 互動式學習體驗

## 功能模組

### 1. KPI 指標庫
- 涵蓋 20+ 常見開發 KPI
- 分類管理：開發活動、Bug與品質、測試覆蓋、效率表現、協作與溝通、技術指標、流程與管理、AI與新技術
- 風險等級標示：🔵 參考、🟡 需注意、🔴 需重視
- 搜尋與篩選功能

### 2. 風險分析系統
- ✅ 正面意義：展示 KPI 的積極作用
- ⚠️ 值得思考：指出潛在風險點
- 💡 改善建議：提供具體改善方案
- Modal 互動展示

### 3. AI 取巧規避分析
- Google Gemini API 整合
- API Key 管理介面
- 🎯 取巧規避手段分析
- 📚 真實情境故事
- ⚠️ 風險警告說明
- 正體中文內容生成

### 4. 互動式體驗
- 響應式卡片設計
- Modal 導航系統
- 展開/收合動畫
- 載入狀態提示

## AI 內容生成

### Prompt 設計
```
請用正體中文回應：分析 "${kpi}" 這個 KPI 指標，說明工程師可能如何取巧規避這個指標。

請按照以下格式回應：
🎯 取巧規避手段
[列出3個具體的取巧方法]

📚 真實故事
[一個生動的情境故事，主角叫阿哲]

⚠️ 風險警告：
[詳細說明風險與後果]
```

### API 配置
- 模型：gemini-1.5-flash
- Temperature: 0.7
- maxOutputTokens: 1000
- 語言：正體中文強制要求

## 使用者流程

### 主要流程
1. **瀏覽 KPI 指標**：使用搜尋和篩選功能找到相關指標
2. **查看風險分析**：點擊卡片開啟 modal 查看詳細分析
3. **輸入 API Key**：在頁面頂部輸入 Google AI Studio API Key
4. **生成取巧分析**：點擊「🎯 工程師如何取巧規避這個 KPI」按鈕
5. **學習與思考**：閱讀 AI 生成的取巧手段、故事和風險警告

### 互動細節
- Modal 支援鍵盤導航（方向鍵、ESC）
