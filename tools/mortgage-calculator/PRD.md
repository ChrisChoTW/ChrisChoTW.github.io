# 房貸試算系統 - 產品需求文件

## 📋 基本資訊
- **產品名稱**: 房貸試算系統
- **技術架構**: Vue.js 3 + Chart.js + Intro.js
- **更新日期**: 2025-09-21

## 🎯 產品定位
多筆貸款管理與換屋財務分析工具

## 核心功能
- 多筆貸款統一管理
- 即時房貸試算
- 換屋財務分析
- 情境決策建議

## 功能模組

### 1. 貸款概況管理
- 支援多筆貸款同時管理
- 貸款參數設定: 名稱、金額、利率、年期
- 自動計算月付金總計
- 攤還表明細查看
- 新增/編輯/刪除操作
- PDF 報告匯出

### 2. 房貸試算器
- 單筆貸款計算
- 輸入參數: 貸款金額、年利率、貸款年期
- 計算結果: 月付金、總利息、總還款、利息占比
- 圓餅圖視覺化
- 攤還表明細
- PDF 匯出功能

### 3. 買賣換屋分析
- 現有房屋參數設定
- 新房參數設定
- 8項指標計算:
  - A. 房屋總損益
  - B. 總剩餘房貸
  - C. 可用現金
  - D. 新房貸款需求
  - E. 原總月付金
  - F. 新月付金
  - G. 月付金變化
  - H. 實際頭期款比例

### 4. 情境分析
- 獲利換屋策略
- 平盤換屋評估
- 虧損換屋應對
- 資金缺口警示

### 5. 概念說明
- 房貸基礎知識
- 計算原理說明
- 操作指引

## 計算公式

### 月付金計算
```
月付金 = 本金 × [月利率 × (1+月利率)^期數] ÷ [(1+月利率)^期數-1]
```

### 剩餘本金計算
```
剩餘本金 = 本金 × [(1+月利率)^總期數-(1+月利率)^已還期數] ÷ [(1+月利率)^總期數-1]
```
